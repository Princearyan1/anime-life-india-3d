# Reference-style visual assets (v0.5 preview)

- Hoodie Teen, Grab3D: https://grab3d.com/models/characters/hoodie-teen/ — CC0. AI-assisted source; disclosure and dedication in hoodie-license.txt. Mesh simplified locally from 300,000 to 50,000 triangles; original rig and walk/run retained.
- Non-Step City Bus, Plane Tree and Strangler Fig, tevy.dev: https://tevy.dev/ — CC0-1.0. Original catalog manifests included alongside models. Bus paint and dimensions adjusted for existing village routes. Trees use instancing and distance culling.

These are playable 3D assets, not the supplied reference image. The preview does not reproduce that image exactly. Seven supplemental idle, sitting, crouch, jump and interaction clips are retargeted from the existing Quaternius animation rig (see ../characters/ANIMATION-LICENSE.txt). Hoodie recoloring supports the existing wardrobe state. Existing NPC clothing remains unchanged.
